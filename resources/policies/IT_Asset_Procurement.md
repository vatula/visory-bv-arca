# IT Asset Procurement and Capitalization Policy

**Effective Date:** January 1, 2026
**Applies To:** All permanent employees and authorized contractors

### 1. Objective
To ensure accurate tracking, capitalization, and lifecycle management of company-owned IT hardware.

### 2. Expense Thresholds and Hardware Types
Any physical IT hardware, electronics, or computer equipment (e.g., laptops, monitors, mobile devices) purchased with a corporate card that exceeds **$1,000.00 AUD** in a single transaction must be treated as a capitalized fixed asset rather than a standard operational expense.

### 3. Required Documentation
For autonomous reconciliation to occur, the transaction must be accompanied by:
* A valid tax invoice.
* A pre-approved IT Asset Request Form.
* The physical Asset Tag ID assigned by the IT department.

### 4. Exception Handling
Transactions exceeding the threshold without the required Asset Tag ID cannot be automatically coded to the standard `Computer Equipment` ledger. The accounting system must suspend the reconciliation and request the missing Asset Tag ID directly from the purchasing employee.
