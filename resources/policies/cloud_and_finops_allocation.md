# Cloud Infrastructure and FinOps Allocation Policy

**Effective Date:** Q3 2025
**Applies To:** Engineering, Product, and IT Operations

### 1. Objective
To maintain accurate unit economics and prevent unallocated "shadow IT" spend across our cloud and infrastructure environments.

### 2. Baseline SaaS vs. Infrastructure Compute
Standard monthly SaaS subscriptions (e.g., Github, Slack, Atlassian, Datadog) and minor infrastructure hosting under $500 AUD are pre-approved for standard department-level allocation. 

### 3. High-Tier Compute Expenditures
Individual cloud service provider charges (specifically AWS, Google Cloud, Azure, and Vultr) that exceed **$500.00 AUD** per transaction trigger mandatory FinOps review. 

### 4. Reconciliation Requirements
To successfully reconcile high-tier compute expenses, the transaction must be explicitly linked to a recognized internal **Project Code** or **Cost Center** to allocate the compute costs accurately. If the invoice does not clearly state the Project Code, the finance automation system must query the technical owner or cardholder to supply the allocation code before updating the ledger.
